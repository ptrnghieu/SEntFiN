# Validation of LLM target completion on FinEntity

_Generated by `python -m absa_data complete-targets --source finentity --validate`._

FinEntity annotates every financial entity, so it can check the completion used on SEntFiN and FiQA. On FinEntity valid, test (273 sentences), each distinct gold target was kept with probability 0.5 (214 given) and the rest hidden; the model (`gpt-6-luna`, prompt `t1-a9946430`) had to find the hidden ones.

| metric | value |
|---|---|
| hidden gold targets | 211 |
| recall, exact match | 94.3% |
| recall, exact or partial match | 95.7% |
| additions | 347 |
| precision, all additions | 59.1% |
| precision, additions typed company / index_market / regulator_government (227) | 88.1% |
| additions on the 44 sentences without any gold target | 15 |


**Reading the precision.** FinEntity does not annotate currencies, most commodities, sectors, countries or generic market references ('Wall Street', 'Japanese shares'), while SEntFiN does. The completion follows SEntFiN's convention, so additions of those types count as errors here although they are intended. Precision within FinEntity's own scope (companies, indices, regulators) is the meaningful number. References that cannot be tied to an entity ('the market', 'the index') are removed by a rule in code.
